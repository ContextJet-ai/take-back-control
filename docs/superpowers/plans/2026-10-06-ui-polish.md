# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Load `design-taste-frontend` and `frontend-design:frontend-design` before Task 1.

**Goal:** Make the site look considered and calm on every page, so a person in distress feels they have arrived somewhere competent. Appealing to look at, comforting to use, nothing that reads as a template.

**Architecture:** No new routes or data. A design pass over tokens, typography, spacing, and the specific components people spend time in (wizard, plan, letter cards), plus real imagery and a few deliberate micro-interactions. Every change is checked in both themes, at 375px and 1280px, under reduced motion, and with Lighthouse accessibility at 100.

**Tech Stack:** unchanged. Motion for the small transitions already present. Image generation for the two placeholder images if a tool is available; otherwise licensed stock.

**Spec:** the original design spec section 8 (UI direction) and the taste skill's pre-flight checklist.

## Global Constraints

- One accent (teal) in both themes. No gradients on text, no glows, no purple.
- Radius 12px on containers and inputs, pill buttons, everywhere.
- Zero em or en dashes. Max two eyebrow labels on the whole site.
- Motion only on `/`, with reduced-motion fallbacks. Wizard and plan stay still except the step fade.
- Hero headline two lines at 1280px. Nav one line, under 80px.
- Every button and input passes WCAG AA contrast in both themes.
- Lighthouse accessibility stays at 100; performance does not drop below 0.9.

## Review Focus

1. Focus rings must be visible in dark mode on the accent-filled button (teal on teal fails). Test: axe run in Task 6 plus a screenshot of a focused primary button in dark.
2. The letter card `<pre>` must wrap long URLs on a 375px screen without horizontal scroll. Test in Task 4 (Playwright asserts `document.documentElement.scrollWidth <= 375`).
3. The quick-exit button must not overlap the wizard's Next button at 375px with the keyboard closed. Test in Task 4.
4. Hero image must not render as a 4:3 letterbox on 1280px with a short headline; it should fill its column. Test: visual check in Task 2, documented with a screenshot in the PR.
5. Light-mode surface token must be visibly different from the page background so cards read as cards. Test: contrast check between `--bg` and `--surface` in Task 1.

```ts
import { describe, it, expect } from "vitest";
import fs from "node:fs";
const css = fs.readFileSync("app/globals.css", "utf8");
function token(block: string, name: string) { return new RegExp(`${name}:\\s*(#[0-9a-f]{6})`, "i").exec(block)![1]; }
function lum(hex: string) { const [r, g, b] = [1, 3, 5].map((i) => parseInt(hex.slice(i, i + 2), 16) / 255).map((c) => (c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4)); return 0.2126 * r + 0.7152 * g + 0.0722 * b; }
function ratio(a: string, b: string) { const [x, y] = [lum(a), lum(b)].sort((p, q) => q - p); return (x + 0.05) / (y + 0.05); }
const light = css.split("@media (prefers-color-scheme: dark)")[0];
const dark = css.split("@media (prefers-color-scheme: dark)")[1];
describe("tokens", () => {
  it("fg on bg passes AAA in both themes", () => { expect(ratio(token(light, "--fg"), token(light, "--bg"))).toBeGreaterThan(7); expect(ratio(token(dark, "--fg"), token(dark, "--bg"))).toBeGreaterThan(7); });
  it("muted on bg passes AA in both themes", () => { expect(ratio(token(light, "--muted"), token(light, "--bg"))).toBeGreaterThan(4.5); expect(ratio(token(dark, "--muted"), token(dark, "--bg"))).toBeGreaterThan(4.5); });
  it("accent-fg on accent passes AA in both themes", () => { expect(ratio(token(light, "--accent-fg"), token(light, "--accent"))).toBeGreaterThan(4.5); expect(ratio(token(dark, "--accent-fg"), token(dark, "--accent"))).toBeGreaterThan(4.5); });
  it("surface differs from bg enough to read as a card", () => { expect(ratio(token(light, "--surface-solid"), token(light, "--bg"))).toBeGreaterThan(1.04); });
  it("no pure black or white tokens", () => { expect(css).not.toMatch(/#000000|#ffffff\b/i); });
});
```
